# Preserved source assets and design references

This folder is kept out of the public website build and Vercel upload.

- `hero-laptop-studio.png`: original supplied hero photograph. The website uses its existing responsive WebP exports.
- `esgrow-mark.png`: original supplied logo. The website uses its existing optimized WebP/icon files.
- `hero-green-atmosphere.png`, `growth-sculpture.png`: earlier hero concepts preserved as design references.
- `project-screens/`: original project captures behind the optimized portfolio images.
- `carousel-reference/`: reference-video frames used for the selected-work carousel.
- `development-previews/`: earlier visual references and layout previews.
- `form-delivery-verified.png`: preserved form delivery screenshot. Byte-identical QA copies were unnecessary duplicates.

These files are retained for future editing and reference. Runtime assets stay in `public/`; the archive is never imported by the application.
